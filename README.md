# AccountantPL · Onsaldo

Два подхода к интерфейсу бухгалтерского приложения, объединённые общей страницей выбора.

| Маршрут | Интерфейс |
| --- | --- |
| `/` | Страница выбора концепции |
| `/variant-a.html` | Accounting Workspace: плотный реестр документов, суммы и контроль VAT |
| `/variant-b.html` | Financial Clarity: финансовый обзор, карточки и переход от общей картины к деталям |

## Локальная проверка

Требуется Node.js 24. Внешних npm-зависимостей нет.

```sh
npm run check
npm run build
python3 -m http.server 8000 --directory dist
```

Открыть `http://localhost:8000`. Для возврата к выбору после просмотра варианта используйте «Назад» в браузере.

## Публикация

Существующий Vercel-проект подключается к этому репозиторию и production-ветке `main`. `vercel.json` явно задаёт статический проект (Other), команду `npm run build` и каталог `dist`. Не требуется backend, база данных или переменные окружения.

В `public/` находятся утверждённая страница выбора и два исходных прототипа. Миниатюры на главной встроены из этих же HTML; проверка гарантирует совпадение с открываемыми страницами. При замене варианта нужно также обновить его встроенный источник в главной странице.

## Границы прототипа

Данные демонстрационные. Нет подключения к бухгалтерскому серверу или KSeF. Financial Clarity использует Google Fonts с системными резервными шрифтами. Подробности визуальной проверки — в `docs/UI_QA_REPORT.json`; Safari и физический iPhone отдельно не проверялись.

`main` — только проверенные изменения. Изменения принимаются через Pull Request.
